# Proiect Git & GitHub – Planificarea aplicațiilor desktop

Acest repository a fost creat în cadrul **Studiului individual nr. 1** la disciplina **Planificarea aplicațiilor desktop** (CEITI, 2026)
și demonstrează utilizarea practică a sistemului de control al versiunilor **Git** și a platformei **GitHub**.

## Ce conține proiectul
* `main.cpp` – fișier de cod sursă utilizat pentru testarea versionării și a commit-urilor.
* `.gitignore` – fișier de configurare pentru excluderea fișierelor sensibile sau temporare.
* `README.md` – documentația de prezentare a repository-ului.

## Funcționalități Git demonstrate
* Inițializarea unui repository local (`git init`)
* Gestionarea modificărilor prin staging și commit-uri (`git add`, `git commit`)
* Sincronizarea proiectului cu un repository remote pe GitHub (`git remote`, `git push`, `git pull`)
* Publicarea unei versiuni oficiale (`Release v1.0.0`)
